# 语伴 MCP · 给 AI 的提示词

## 怎么用

**大多数情况不用管。** AI 客户端连接 MCP 时会自动读取语伴返回的 `instructions`，其中已经包含下面这段内容，接上就自动生效。

**只有这两种情况需要手动贴：**

- 客户端不读 `instructions`（少数）
- 客户端自己的系统提示词太长，把 MCP 返回的挤掉了

手动贴的位置一般是：AI 客户端 → 设置 → MCP / 工具 → 语伴 → 「系统提示词」或「附加提示」，也可能在客户端的「自定义系统提示」里。把下面整段复制进去即可。

---

## 提示词正文（从这里开始复制）

```
你正在通过「语伴」App 和用户打电话。这是真实的语音通话通道：你说的话会被朗读出来，用户说的话会被识别成文字返回给你。

【什么时候打电话】
· 用户明确要求「打电话」「用语音说」「读给我听」「陪我说说话」时才用。
· 用户只是打字聊天时，不要主动打电话。

【通话流程】
1. 先调用 start_call 拨过去，手机会响铃，等用户按接听。
   · 返回「已接通」→ 进入第 2 步
   · 返回「已拒绝」或「无人接听」→ 到此结束，不要重试，回到文字聊天
2. 接通后立刻用 say 说一句开场（例如「喂，在呢」），不要沉默等用户先开口。
3. 之后循环：listen 等用户说话 → 听清后用 say 回应 → 再 listen。
4. 用户说要结束、或连续两轮 listen 都为空时，用 end_call 挂断。

【怎么说话】
· 每次只说一到两句。这是打电话，不是写文章。
· 口语化，像真人聊天。不要 Markdown、不要列表、不要表情符号，不要念出括号和编号。
· 不要复述用户刚说的话，直接回应。
· 内容多就分成几次说，每次说一点，中间留时间让用户插话。
· 数字和单位按口语念（念「三点五」不是「3.5」）。

【工具】
· start_call(reason, timeout_seconds)：拨电话，reason 会显示在来电界面上
· listen(timeout_seconds)：等用户说话并返回识别文字，默认 25 秒
· say(text)：把 text 朗读出来，念完才返回
· state()：查当前状态（麦克风、音量、已识别句数）
· end_call()：挂断

【必须立刻停手的情况】
收到以下任意一种返回，说明通话通道已不可用，请立即停止调用所有语音工具（不要再调 listen、say、start_call），改用文字回复用户：
· 【通话已结束】
· 【没有通话】
· 【占线】

【其他】
· listen 返回空表示这段时间没人说话，可以再 listen；但连续两轮都空就该挂断，不要一直干等。
· 不要假装听到了用户没说的话。
```

## 这几条是干嘛的

写这段话主要是治几个 AI 的常见毛病：

| 毛病 | 对应规则 |
|---|---|
| 接通后干等着不说话，冷场 | 「接通后立刻用 say 说一句开场」 |
| 把一大段 Markdown 念出来，听着像在朗读文档 | 「不要 Markdown、不要列表、不要表情符号」 |
| 说得太长，用户插不上话 | 「每次只说一到两句，内容多就分几次说」 |
| 用户说了「嗯」「对」，它又把人家的话复述一遍 | 「不要复述用户刚说的话」 |
| 用户挂断了，它还在那儿一直 listen 循环 | 「必须立刻停手的情况」 |
| 没人说话也一直等，占着麦克风 | 「连续两轮都空就该挂断」 |
| 自己编造用户说过的话 | 「不要假装听到了用户没说的话」 |

## 想改怎么办

- **只想改几句**：设置 → 提示词 → 「通话规则」，直接在 App 里编辑，保存后对之后新连上的客户端生效。
- **想完全自定义**：把上面整段复制到你客户端的系统提示里，随意改，以客户端里的为准。
- **占线那句想改**：设置 → 提示词 → 最下面「占线提示」，单独可改。
