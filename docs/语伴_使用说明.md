# 语伴 App · 使用说明

> 配套文档：`语伴_安装说明.md`（讲安装和风险提示，这份只讲怎么用）

---

## 一、界面长什么样

打开后从上到下是四块：

```
☰          （对话标题）          ⚙
────────────────────────────────
            头像
            名字
           在线 / 正在听… / 正在说…

       对话气泡列表（你来我往）

────────────────────────────────
         [ 输入消息…  ]  ➤
      🎤 麦克风        📞 通话
```

- **左上 ☰**：拉出通话记录抽屉
- **右上 ⚙**：设置
- **中间头像**：可以上下滑（见第六节手势）
- **底部**：输入框（打字聊天）、麦克风、通话

> 底部输入框只在**待机**和**本地通话**时出现。MCP 来电和 MCP 通话过程中它会自动收起——因为那个输入框只能喂给软件内置的 AI，外面打进来的 AI 读不到，留着只是碍眼。

---

## 二、第一次用，先填 Key

这个应用**不内置任何 API Key**，不给它配置就发不出声音。点右上角 ⚙，至少填这两项：

| 卡片 | 干嘛用的 | 去哪拿 |
|---|---|---|
| **对话模型** | 决定 AI 有多聪明、怎么回答 | 默认填的是 DeepSeek 的地址，去 platform.deepseek.com 申请 Key |
| **识别模型** | 把你的话转成文字（听写） | 默认阿里云 DashScope 的 `qwen3-asr-flash` |
| **语音模型** | 把回复读出来（发声） | 默认 ElevenLabs，需要额外填「音色 ID」 |

填完点「保存」。三样都齐了才是一套完整的语音对话。

> 只要接口是 OpenAI 兼容格式，地址和模型名可以随便换，不限于上面这几家。

---

## 三、怎么开始通话

底部那个 **📞 通话** 按钮有两个含义，看你当时在什么状态：

**情况 A：你自己想打**
点一下「通话」→ 麦克风自动打开 → 直接说话就行 → 再点一下挂断。

**情况 B：AI 打给你**
屏幕会弹出「📞 来电：……」，同时响铃。这时：

- 点 **📞 通话** = 接听
- 点 **🎤 麦克风** = 拒接

接听后就进入实时对话，你说话它回话，全程语音。

---

## 四、通话中会看到什么

- **状态文字**会变：`在线` → `正在听` → `正在思考…` → `正在说…`
- **字幕**显示当前这句话（字幕模式见下一节）
- 说话时头像周围有一圈声波在动，音量越大波纹越明显

> 麦克风按钮下方那行小字：没开麦时是「点我说话」，通话中是固定的「正在听」。头像下方那行状态文字才是设置里可自定义的。

**挂断**：再点一次「📞 通话」。挂断后如果是从别的应用来的电话，会自动跳回你原来的应用。

**每通电话都是新记录**：AI 打来时界面当场清成一条全新的空对话，不会拖着上一次的内容；挂断后再打来又是新的一条。

---

## 五、重听 AI 说过的话

AI 说过的每一句语音都会自动存一份 MP3 到手机上：

- **应用私有目录**（重播走这里，不需要任何权限）
- 另外复制一份到 `Music/语伴/`，你可以用文件管理器或音乐 App 直接找到

**怎么重播**：在对话里**点一下那条 AI 消息**就开始播，不用长按。播的是当时存下来的那份文件，**不会重新请求接口、不花额度**。

长按消息还有菜单：「复制」「重新播放」。

> 存的时候是按句存的。如果那句是合成失败、走的系统 TTS，就没有音频文件，点了会提示「这条没有保存的语音」。

## 六、手势（挺关键，界面上没提示）

| 操作 | 效果 |
|---|---|
| 头像 **向下滑** | 收起对话列表，进入大字幕模式（只留头像和当前这句话，适合躺着听） |
| 头像 **向上滑** | 展开对话列表 |
| 点字幕下方的「⌃ 展开对话」 | 从字幕模式回到对话列表 |

字幕模式是给"边听边看这一句"设计的，字更大、更专注。想翻聊天记录就滑回来。

---

## 七、打字聊天

除了说话，也可以直接打字：

1. 点输入框 → 系统键盘弹出
2. 输入后点 **➤** 发送

想用应用自带的浮动小键盘：输入框获得焦点后，界面上会出现一个深色小键盘面板，可以拖动、可以拉宽，右下角「✕」收起。它上面的「中」字键可以切回系统输入法。

---

## 八、管理对话记录

点左上 **☰** 拉出抽屉，所有通话记录都在里面。

每条记录长这样：

```
  上周的语音测试
  13:20   今天聊了聊那个 MCP 的事情…
```

上面是标题，下面一行是**最后一次通话的时间 + 最后一句内容**（今天显示 `13:20`，昨天显示「昨天」，更早显示「周三」或「11月8日」）。当前打开的那条会整块高亮，置顶的会带 📌。

**单个操作**（长按某条记录）：
- 置顶 / 取消置顶
- 重命名
- 放入文件夹
- 删除

**快捷操作**：在某条记录上**向左划** → 出现删除，松手即删（划得够远才触发）。

**批量操作**：抽屉右上角「选择」→ 勾选多条 → 可以「全选」「放入文件夹」「删除选中」。

**文件夹**：右上角「＋ 文件夹」新建。点文件夹标题可以折叠/展开；长按标题可以重命名或删除文件夹（文件夹里的记录不会被删，会回到未分类）。

**新建对话**：右上角「＋」，开一段全新的。

> MCP 通话的记录是**每通自动一条**，通话过程中就实时往里写（你说的话和 AI 说的话都会记），不用等挂断。

## 九、设置项逐个说

| 分区 | 项目 | 说明 |
|---|---|---|
| **MCP 服务地址** | `http://127.0.0.1:8765/mcp` | 进阶用，见第十节。点「复制」可以拿走 |
| **显示** | 名字 | 头像下方显示的名字，改成什么都行 |
| | 状态 | 待机时的文字，默认「在线」 |
| | 正在听时 / 正在说时 / 思考中 / 来电时 | 各阶段的提示文字，可以改成你喜欢的措辞 |
| | 来电提示前缀 | 来电时显示在原因前面的符号，默认「📞 来电：」 |
| | 流式输出 | 开着的话回复逐字出现，关掉就是整段弹出 |
| **外观** | 更换头像 / 更换背景 | 从相册选图 |
| | 背景图透明度 | 拖动立刻生效 |
| | 颜色定制 | 我的气泡色、AI 气泡色、字体颜色、名字颜色、状态文字颜色 |
| | 输入区透明度 | 只管底部输入框和按钮那一块 |
| **提示词** | 系统提示词 | 决定 AI 的性格和说话方式。默认是"口语化、简洁、别用 Markdown" |
| | 通话规则 | 发给外部 AI 的通话规则（MCP 用），比如"回复要短""连续两轮没声音就挂断" |
| | 占线提示 | 你正在本地通话时，外部 AI 打过来会收到的回复。默认叫它"立即停止调用"，可以自己改 |
| | *(三个文本区右侧都有「复制」)* | 点一下整段进剪贴板，不用长按选中 |
| **通用** | 自动命名 | 根据内容自动给对话起标题 |
| | 声波图 | 把语音的频谱特征一并发给 AI，让它能"看"出你的语速、停顿、语调 |
| | **来电铃声** | 选任意系统铃声，也可以选「静音」。AI 打过来时就响这个 |
| | **通知权限** | 想看到通知栏那条保活状态，就从这里开 |
| | 授权悬浮窗 / 使用情况访问 | 来电弹窗、自动识别来源 App |
| | **导出 / 导入** | 把全部配置导出成文件，换手机或分享给别人时直接导入，省得重填 |

> 「声波图」这个开关挺有意思：打开后 AI 不只知道你说了什么，还能知道你语速快不快、停顿多不多、语调平不平。

## 十、进阶：让 AI 主动给你打电话

这是这个应用真正的玩法。

设置页第一张蓝色卡片里的 **MCP 服务地址**，是应用在本机开的一个服务：

```
http://127.0.0.1:8765/mcp
```

任何支持 MCP 协议的 AI 客户端，把这行地址加进去，那个 AI 就获得了给你打电话的能力。它能调用这些工具：

| 工具 | 作用 |
|---|---|
| `start_call` | **打给你**：手机响铃，你决定接不接 |
| `say` | 在通话里开口说话 |
| `listen` | 等你说话，把你的话变成文字拿回去 |
| `state` | 查现在的通话状态 |
| `end_call` | 挂断 |

**能玩出什么花样：** 让 AI 在你设定的时间打过来提醒你吃药、陪你练口语、给你读新闻、当你睡前聊几句的对象。因为它能拿到你真实的语音，而且会等你回话，不是发一条文字就结束。

**注意：** 这个地址是 `127.0.0.1`，**只监听本机**，同一个 Wi-Fi 下的其他设备也连不上，外网更连不上。所以它只在"手机上的 AI 客户端 + 手机上的语伴"这个组合里生效。

**占线的情况：** 你正在用软件内的本地 AI 通话时，外部 AI 打过来会收到「【占线】…请立即停止调用语音工具」的回复，不会插进来打断你。这句话的措辞可以在 设置 → 提示词 → 最下面自己改。

## 十一、常见问题

**Q：点了通话没反应 / 没声音？**
A：先检查设置里三个模型的 Key 是不是都填了。另外确认给过麦克风权限。

**Q：AI 一直不说话？**
A：多半是识别模型（ASR）的 Key 没配好，你的话没转成文字，它自然没得回。

**Q：点 AI 的消息提示「这条没有保存的语音」？**
A：说明那句话是走系统 TTS 念的（比如 ElevenLabs 出错时代替发声），没有音频文件可存。正常走 ElevenLabs 的句子都能重播。

**Q：MCP 通话时输入框去哪了？**
A：自动收起了。那个输入框只能把文字发给软件内置的本地 AI，外部打进来的 AI 读不到，通话中留着没意义，所以整块隐藏、只留麦克风和挂断。

**Q：它说到一半停了？**
A：网络断了，或者语音模型超额。检查一下 Key 的余额。

**Q：怎么彻底退出？**
A：返回桌面就行，通话会结束，但后台服务继续常驻（通知栏那条就是它），这样 MCP 才随时能用。真要彻底停掉，去系统设置里强制停止。

**Q：换手机怎么迁移？**
A：旧手机 → 设置 → 通用 → 「导出」；新手机导入那个文件，Key 和所有配置都在里面。

**Q：通知栏一直挂着「语伴 · 运行中」？**
A：这是**保活标记**，不是消息提醒。MCP 服务要能随时被 AI 调用，进程就不能被系统回收，所以用一条常驻通知把应用挂在后台。它不响铃、不弹窗，只是安静地待在通知栏里告诉自己还活着。点它可以直接回到应用。

- 如果看不到这条通知：设置 → 通用 → 点「通知权限」那一项，按提示开启。没授权也不影响功能，只是看不到这盏"指示灯"。
- 想彻底停掉：把应用从最近任务里划掉，或者系统设置里强制停止。停了之后 MCP 就没法再打进来了。

## 一句话上手流程

> 装好 → ⚙ 填三个 Key → 保存 → 点「📞 通话」→ 说话。
> 想安静听就往下滑头像，想翻记录就往上滑。
