# 语伴 App · 安装说明

> 版本 v1.16 · 116 KB · 适用 Android 10 及以上
> 安装包：`语伴_v1.16.apk`

---

## 这是什么

一个「打电话式」的 AI 语音对话应用。接通后会像打电话一样跟 AI 聊天：你说话，它听懂并开口回答，全程语音，屏幕上是对话字幕。

它的 AI 接口是开放的，你填自己的 API Key 就能用，不绑定任何账号体系。

---

## ⚠️ 安装时可能看到「风险提示」

**这是手机系统的通用模板提示，不代表这个应用真的有问题。**

**为什么会有：** 这个应用没有上架任何应用商店，属于「未知来源」的自签名应用。国产手机（尤其是 OPPO / 一加 / 真我 的 ColorOS、realme UI，以及小米的 MIUI / HyperOS）在安装这类应用时，会统一弹出一段风险文案，常见措辞包括：

- 恶意占用系统资源
- 自动捆绑安装
- 自动修改系统配置
- 频繁发送骚扰信息

这段文字是**「此类未知应用可能存在的风险类型」清单**，不是对这个 APK 的实际检测结果 —— 系统把可能性一次性列出来给你看。任何没上架商店的个人应用都会被这么提示，包括很多知名开源软件。

判断依据是「包名不在应用商店的云端信誉库里」，而不是看了代码。

### 怎么处理

1. **安装时**：出现「继续安装」/「仍要安装」/「信任此应用」，点它即可。
2. **装完后如果手机管家反复提醒**（这就是「老是跳风险」的原因，管家每次扫描都会重新报一次）：
   - 打开手机管家 → 病毒扫描 / 应用安全检测
   - 找到「语伴」→ 加入信任名单 / 忽略 / 允许
   - 加一次之后就不会再报了

## 这个应用申请了哪些权限，分别用来干嘛

| 权限 | 用途 | 是否必须 |
|---|---|---|
| 麦克风 | 通话时收音、语音识别 | 必须 |
| 网络访问 | 调用你自己填的 AI 接口 | 必须 |
| 悬浮窗 / 显示在其他应用上层 | 来电时弹出接听界面 | 用「来电」功能时需要 |
| 使用情况访问 | 自动判断你当前在哪个 App，作为对话上下文 | 可选，不授权也能用 |
| 前台服务 | 保持进程不被系统回收，外部 AI 才能随时打进来 | 必须 |
| 通知 | 在通知栏显示「语伴 · 运行中」这条保活标记 | 建议开（不开也能用，只是看不到标记） |

每一项都需要**你在系统设置里手动点「允许」**才会生效。Android 的机制决定了应用无法自己偷偷打开这些开关，授权过程你全程可见。

## 这个应用不具备的能力（重要）

| 提示里的说法 | 实际上 |
|---|---|
| 自动捆绑安装 | ❌ 未声明安装应用权限（`REQUEST_INSTALL_PACKAGES`），**技术上无法安装任何其他应用** |
| 自动修改系统配置 | ❌ 未声明修改系统设置权限（`WRITE_SETTINGS`），**无法改动系统设置** |
| 频繁发送骚扰信息 | ❌ 未声明短信、通讯录权限，**无法发短信、读不到你的联系人** |
| 开机自动启动 | ❌ 未声明开机广播权限，**手机重启后不会自己起来** |
| 常驻后台 | ⚠️ **这个有，是故意的**。为了让外部 AI 能随时打进来（MCP 功能），应用打开后会保持一个前台服务，通知栏那条「语伴 · 运行中」就是它。它不响不弹、只在通知栏挂个标记。你从最近任务划掉或强制停止，它就没了 |

如果仍然不放心，可以用 Android 自带的「应用信息 → 权限」逐项核对，或把 APK 丢进 VirusTotal 查一遍 —— 查出来的结果会比手机管家的模板文案具体得多。

## 首次使用

1. 打开应用 → 右上角 **⚙ 设置**
2. 填写你自己的 AI 接口信息：
   - **对话模型**：接口地址、模型名、API Key（默认填的是 DeepSeek 的地址，Key 需要你自己准备）
   - **识别模型**：默认阿里云 DashScope 的 `qwen3-asr-flash`（负责听写）
   - **语音模型**：默认 ElevenLabs（负责发声），需要填音色 ID
3. 点「保存」，然后按底部「通话」开始

> 应用**不内置任何 API Key**，必须由你自己填写。
> 所有网络请求直接发往你填写的接口地址，不经过任何第三方中转服务器，也没有统计、埋点或广告 SDK。

## 常见问题

**Q：提示「应用未安装」或「签名冲突」？**
A：手机上装过其他签名版本的同名应用。先卸载旧版再装这个。

**Q：会不会偷偷录音？**
A：只在通话接通期间使用麦克风，挂断立即停止（服务也一起停）。通话时系统状态栏会显示麦克风使用指示器，你能随时看到。

**Q：需要联网吗？**
A：需要。语音识别和对话推理都在云端完成，离线无法使用。

**Q：能换自己的 AI 服务吗？**
A：可以。设置页里把接口地址、模型名换成任何兼容 OpenAI 格式的服务都行。
